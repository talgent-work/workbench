# Security Policy

## Reporting a vulnerability

Do not report security vulnerabilities in public issues. Report them privately through
[GitHub's private vulnerability reporting](https://github.com/talgent-work/workbench/security/advisories/new).

Include what is affected (process, page or API), the release you run, the steps that reproduce
it and the impact you observed. We acknowledge a report within three working days, keep you
informed while we fix it, and credit you in the advisory unless you prefer otherwise.

## Supported releases

Every merge to the main branch is a release, and fixes land in the next one. Only the latest
release receives security fixes; upgrade to it before reporting.
